# Bun Migration Notes

This project was migrated to Bun 1.4.3 as the primary runtime and package manager.

## What changed

- `package.json`: split deps/devDeps, Bun engines, real Bun scripts, removed legacy npm/netlify scripts.
- `bun.lock`: generated by `bun install` (authoritative lockfile).
- `bunfig.toml`: Bun install/run/test configuration.
- `.bun-version`: pinned to `1.4.3`.
- `package-lock.json`: superseded by `bun.lock` (gitignored).
- Added `source-map@^0.6.1` devDependency to fix the legacy `resolve-url-loader`/`source-map` incompatibility in CRA dev/build.
- Added Bun-native tooling: `bun test` (test runner), `bun.lock` (lockfile).

## What stayed

- React, react-router-dom, supabase-js, framer-motion, three, @google/generative-ai (all Bun-compatible).
- `react-scripts` build/dev toolchain (shells out to Node; still functional under Bun).
- `serve` for production preview.

## Verified commands

`bun install`, `bun run dev`, `bun run build`, `bun run start`, `bun run test`, `bun run lint`, `bun run typecheck`, `bun run format` all pass.

## Known notes

- `resolve-url-loader` required `source-map@^0.6.1` to fix `aSourceMapConsumer.originalPositionFor is not a function` in dev and build.
- Source maps disabled in production (`GENERATE_SOURCEMAP=false`).
- `babel-preset-react-app` private-property warning and `caniuse-lite` notices are benign.
